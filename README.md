# homebrew-tap

Homebrew Tap for [jmt-labs](https://github.com/jmt-labs) tools.

## Installation

```bash
brew tap jmt-labs/tap
brew install forgecrate
```

## Tools

| Tool | Description |
|------|-------------|
| [forgecrate](https://github.com/jmt-labs/forgecrate) | Reproducible Claude Code setup for any repository |

## Update

```bash
brew upgrade forgecrate
```
